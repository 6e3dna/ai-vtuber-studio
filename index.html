Как выйти в эфир

1. Персонаж

Можно сразу вести эфир на встроенном жёлтом ведущем. Чтобы заменить его:

  1. Скопируйте «Промпт персонажа» и сгенерируйте сетку без губ: на месте рта гладкая кожа.
  2. Скопируйте «Промпт губ» и сгенерируйте второй лист: только губы, тот же порядок и цифры.
  3. Загрузите оба листа. Студия снимет зелёный фон, обрежет губы и сама поставит их на лицо в ширину ползунка.
  4. Нужна сетка 4×4 (16 поз) или старая 5×2. Переключатель сетки стоит над загрузкой. В углу кадра — цифра.
  5. Загрузите сетку или файлы. Ползунком уберите зелёный фон и зелёную кайму.
  6. Нажмите «Умная авто-разметка» — уйдёт один коллаж, модель вернёт, какая цифра какой позе соответствует.
  7. Включите калибровку и кликните центр губ на каждом кадре. Ширину, высоту и изгиб улыбки задайте ползунками — у каждого фото они свои. Красная дуга показывает размер.

2. Голос в Edge

  1. Windows: Параметры → Время и язык → Речь → добавить русский.
  2. Edge: edge://settings/languages — русский в списке языков.
  3. Во вкладке API выберите Microsoft Dmitry (приоритет) или любой ru-RU. Скорость 0.7–1.5, тон 0.6–1.4. Проверьте кнопкой «Тест голоса».

3. Мозг

Ключ TeamoRouter, база https://api.teamorouter.com/v1. Для проверки — deepseek-flash-free, для эфира — deepseek-flash-1017. В запрос всегда уходят temperature 0.7, max_tokens 180 и thinking disabled. Системный промпт статичный, в пользовательском сообщении — кадр 448×252 JPEG 0.55, три строки памяти сюжета, распознанная речь и новые реплики чата. Очередь: чат, затем скачок звука или сильный сдвиг кадра, затем таймер. При 429 студия ждёт 10 секунд. Если модель не умеет картинки (400), эфир продолжается текстом.

4. OBS

  1. Источник: захват окна браузера со студией или захват экрана.
  2. Для хромакея персонажа включите «Хромакей фон» — сцена станет #00FF00, видео подложка спрячется (анализ кадра при этом читает видео, если оно запущено).
  3. «Режим OBS» прячет пульт. Вернуть: Esc или кнопка в углу.
  4. Фильтр Color Key в OBS: зелёный #00FF00, подобрать Similarity.

5. Чат VK Видео / Rutube

Браузер сам в чат площадки не заходит. На компьютере нужен мост: программа читает чат и шлёт строки в WebSocket. Студия переподключается сама, пока стрим включён и галочка моста стоит.

// chat-bridge.mjs
// npm i ws && node chat-bridge.mjs
import { WebSocketServer } from "ws";
const wss = new WebSocketServer({ port: 8765 });
function push(user, text) {
  const data = JSON.stringify({ user, text });
  for (const c of wss.clients) c.send(data);
}
// Дальше вызывайте push(имя, текст) из API чата VK Видео или Rutube.

Без моста проверьте реакцию кнопкой «Тестовый вброс» и своими сообщениями. Настройки и точки рта лежат в браузере и в файле пресета.
