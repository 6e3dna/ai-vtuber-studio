# Пилот-2 · AI VTuber Studio

Однофайловая студия ведущего для OBS и эфира. Откройте `index.html` в браузере — сборка не нужна.

## Что внутри

- 16 поз (сетка 4×4) и старый режим 5×2
- Персонаж и губы — два отдельных листа. Студия снимает зелёный фон и сама ставит губы на лицо
- Челюсть двигается по речи, без чёрного овала
- Хромакей, OBS-режим, перетаскивание и масштаб колёсиком
- Пресеты JSON и настройки в localStorage
- Режиссёр через TeamoRouter (DeepSeek Flash)
- Голос браузера или локальный TTS на этом ПК (Piper / Silero, OpenAI-совместимый `POST /v1/audio/speech`)

## Как открыть

Дважды щёлкните `index.html` или запустите любой статический сервер из этой папки.

Ключ API вводится на вкладке «API» и хранится только в браузере.
